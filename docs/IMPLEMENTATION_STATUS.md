## Fixed and verified in source

Inline attribution (26 Sep, contracts N1-N7; reviewer view, safety argument and non-claims in `docs/INLINE_ATTRIBUTION.md`)
- `prompt_templates.py`: the map prompt REVERSES the impersonal rule: decision/task/description are written in facilitator style attributing to the fragment's labels (`S3 a propus ...; S1 a aprobat`), the label is the only allowed way to name a person (no proper names, no "doctorul X"), `owner_mention` still carries the verbatim mention; the synthesis prompt asks for a short labelled narrative (RO/RU/EN) and receives each item's speakers (`[D] (S2, S1) ...`), never an owner name.
- `schemas.py`: `speakers` (array of strings, maxItems 3) required on every `MAP_SCHEMA` item and defaulted on the pydantic mirrors; `merge.py` unions `speakers` (ordered, capped at 3).
- `validator.py`: `ground_speaker_labels(text, speakers, cited_segments) -> (text, speakers, repaired)` and `ground_labels_in_text`; the allowed set is the cited segments' labels, the replacement is the cited label with the most speech (`speech_seconds`, else duration). `llm_engine.py` applies it once on the merged dicts, grounds the summaries/agenda against the transcript's label set, stamps `speaker_label_style="labels"`, and on any repair sets `needs_name_review` and appends ONE medium `NOTĂ AUDIT: atribuirea vorbitorilor a fost corectată automat ...` item.
- `attribution_render.py` (new): `LABEL_RE`, `SPEAKER_RE`, `ANON`, `build_label_map(transcript, locale)`, `render_text`, `render_minutes(minutes, transcript)` (deep copy; ro/ru/en forms on label-styled prose; `EvidenceQuote.speaker` is the cited segment's `display_speaker` and a speaker-derived owner resolves only when every evidence turn is printable and in that cluster; tokens of clusters absent from the transcript and clinical `S<n>` notation are left as written; impersonal minutes keep their prose byte-identical). `is_speaker_label` / `labels_in` / `sub_labels` share the clinical guard with `validator.ground_labels_in_text` and the translation guard.
- `models/extraction.py`: `MinutesOfMeeting.speaker_label_style: Literal["impersonal","labels"] = "impersonal"`. `models/transcript.py`: `attribution_basis: Literal["voiceprint","reviewer_label"] = "voiceprint"`; `corrected` now requires `confirmed_display_name` and (`speaker_id` or basis `reviewer_label`); `confirmed` still requires `speaker_id`; legacy migration untouched.
- `review.py`: `GET /minutes?names=resolved|labels` (default resolved, rendered against the stored transcript), `POST /translate` returns resolved text, `PUT /minutes` stores the body verbatim. `generator.py`: PDF/DOCX render a `render_minutes` copy (legend, footer, `Vorbitor N` owner column unchanged). `translation_service.py`: label-preservation rule in the prompt, per-field Romanian fallback with a WARNING when a label set changes; always translates stored token text.
- `speakers.py`: `SpeakerDecisionRequest.action` gains `label` with `display_label` (2-60 chars trimmed, not `^Speaker \d+$` / `^S\d+$`, 400) or `attendee_id` (any `meeting.attendees[].id`, guests included; 404 when unknown); writes `corrected` / `speaker_id=None` / `attribution_basis="reviewer_label"` / `printable_name` per floor through the same code path as confirm (blockers, revision bump, evidence/owner rewrite, documents); `SpeakerCluster` gains `label_options[{id,name,role,is_guest}]` and `current_label`. The audit event is recorded as `correct` with `person_id=None` and the label snapshot until `SpeakerAttributionEvent.action` lists `label` (see Not done).
- Frontend: `SpeakerConfirmationPanel` "Someone else" menu with enrolled voices / attendees & guests / custom label sections and an "Assigned —" state; `client.getMinutes(id, names?)`, `confirmSpeaker` with `display_label`/`attendee_id`; `npm run build` passes (Group F).

Storage and API
- `repository._read_json` no longer swallows errors; corrupt or non-object store files raise instead of silently returning `{}`.
- `repository._write_json` uses a unique temp filename per writer.
- `save_meeting` refreshes `updated_at`; `delete_meeting` now cascades to transcript, minutes, deliveries, and on-disk artifacts via `file_manager.purge_meeting_artifacts`.
- `file_manager` validates `meeting_id` against `^[A-Za-z0-9_-]{1,64}$` before joining it into any path.
- Domain exceptions are mapped to HTTP status codes in `main.py`, so a rejected upload returns 400 and an unknown/unsafe id returns 404 instead of 500.
- CORS no longer appends `"*"` alongside `allow_credentials=True`.
- `/ready` reports `llm_service: {endpoint, engine, model, connected, loaded, mode}` via `llm_client.health()` (`/api/version` + `/api/tags`, never loads the model) and `/api/ps` for `loaded`; `ready` is false when `REQUIRE_LOCAL_LLM` and the LLM is not connected. Lifespan logs CRITICAL (does not exit) in that case.
- `/docs` and `/redoc` no longer reference a CDN: they render from bundles vendored under `backend/app/static/docs` when present, otherwise from a self-contained offline route table. No bundle is vendored today, so the interactive Swagger UI is not available, only the offline reference.
- `/audio/stream` returns the real container MIME type; upload is non-blocking, rejects replacement during an active run, deletes the previous recording, and resets `normalized_audio_path`, duration, error and review state.

Pipeline
- Every blocking stage (normalize, transcribe, diarize, document generation) runs via `asyncio.to_thread`; the event loop is no longer held for the whole run.
- `POST /pipeline/start` persists `PREPROCESSING`/5 before scheduling the background task, so an immediate `/status` poll cannot return the previous run's result and a second start is rejected.
- Concurrency guard uses `ACTIVE_PROCESSING_STATUSES`, derived from the terminal states.
- A re-run bumps the revision (`_next_revision`) instead of overwriting Rev1 exports; `error_message` is cleared at the start of a run.
